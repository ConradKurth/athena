# Athena UraGuard — Off-Page Authority (Lever 4)

**Why this exists:** The hub-and-spoke content shipped and ranks on micro long-tail, but is absent from every money head term ("incontinence liner/pads", "bladder leak pads" — not in top 100). Root cause is an **authority floor: 35 referring domains (mostly spam) vs 421 (Attn:Grace) / 977 (Because Market)**. No amount of on-page work outranks a 10–30× domain-authority gap. This is the **only lever that unlocks new money-term traffic** — and the slowest (60–90 day payoff). Start now.

**Goal:** 35 → 60 real referring domains in 60 days, 100+ in 90 days. "Real" = topically-relevant, non-spam, ideally dofollow.

**This is a different motion from `outreach/`** (which is sales prospecting via Gmail drafts). Reuse the compliant-copy discipline and the gmail-admin CLI for sending, but the targets and asks are link-acquisition, not sales.

## The asset

- `targets.csv` — prioritized target list. Columns: category, target, type, value_tier, attainability, contact_path, pitch_angle, confidence, status.
- `pitches.md` — one template per pitch type. All compliant (see below).

## Prioritization (work top-down)

1. **Fast, transactional (weeks):** FSA/HSA qualification partners (Truemed, FSAstore/HSAstore) — they *want* DTC brands listed; near-automatic dofollow brand pages.
2. **Fast, founder-led (weeks):** journalist-request platforms (Connectively/HARO, Featured, Qwoted) — the **physician-founder** is a strong expert source; 1–3 placements/month realistic.
3. **Medium, editorial (1–2 mo):** caregiver/eldercare blogs (DailyCaring, AgingCare, Caring.com) — pitch inclusion in existing "best incontinence products" roundups.
4. **Medium, authority orgs (1–2 mo):** continence nonprofits (NAFC, Simon Foundation) resource/product pages.
5. **Slow, high-value (2–3 mo):** Wirecutter / Healthline / Verywell / Good Housekeeping roundup inclusion; AARP. Low hit rate, high payoff.

## Compliance (non-negotiable in every pitch)

Allowed: dryness / extra-dry, **liner worn inside** the underwear (form factor), thin / discreet / breathable, overnight leak security (performance), dignity / comfort / confidence, **physician-founded**. The antibacterial / "reduces bacterial exposure" claim is *permitted* per the 2026-08-06 counsel reversal but keep it optional — many editors and health directories reject device-style claims, so lead with dryness + dignity.

## Measurement (monthly)

- **DataForSEO** backlinks (`api_request` — works via the `~/.claude.json` password): referring domains count + new/lost.
- **GSC** Links report: top linking sites, cross-check new RDs.
- Log new live links in `targets.csv` status column with the date.
